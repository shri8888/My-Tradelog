Connect your Google Sheet

  1. Create a Google Sheet, then open Extensions > Apps Script.
  2. Paste in the contents of Code.gs and set your own secret in TOKEN.
  3. Click Deploy > New deployment > Web app. Run as Me, access Anyone.
  4. Copy the Web app URL and paste it below with the same secret.

Open the bookmark link on another device or browser to connect automatically. The URL and secret sit after the # in the link, so they are never sent to the website host or stored in the page's code. Don't put them in CONFIG if this page is hosted publicly.
